Guide & Firebase Setup

1. Firebase Setup Steps

Create a Firebase project at firebase.google.com, enable Authentication (Email/Password), and create a Cloud Firestore database in production mode.

2. Firestore Security Rules

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /artifacts/{appId}/public/data/{document=**} {
      allow read, write: if request.auth != null;
    }
    match /artifacts/{appId}/users/{userId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}

3. PWA Installation

Android (Chrome): Tap menu (3 dots) -> "Add to Home screen" or "Install app".
iOS (Safari): Tap Share button -> "Add to Home Screen".

4. Features & Behavior

• Timezone: Asia/Kuala Lumpur.
• Sign Up: Works once only for the business owner.
• Inactivity Auto-Logout: After 2 hours.
• Offline Sync: Automatically syncs when back online.
